            About LAYA and JEV
            
LAYA · open-source model from Convai Innovations
              (convaiinnovations/laya), runs on this machine, free. A ModernBERT-based
              encoder: it does not write text; in one pass it reads the prompt and evidence and gives
              a probability to each answer option.

            
JEV · TypeSafe's hosted model (jev-latest), called over the
              API, paid per call, offered only when TYPESAFE_API_KEY is set. Same
              request format and same kind of answer; its internals are not published.

            
What we found so far (notebook 06): given one detector's result, JEV only echoed it (FP1: it repeated D2 on all 180 clips).
              As judges between detectors, LAYA follows the detector listed first and never abstains.
              Treat the judge's answer as an experiment, not a better detector.

How to read this

          

            EER: error rate when missed spoofs equal false alarms; 50% is chance.

            Missed spoofs: spoof clips called bona fide, out of all spoof clips.
            False alarms: bona fide clips called spoof, out of all bona fide clips.
            Each is a share of its own class, so class imbalance does not skew it. Both are what the
            app decides at the detector's own threshold, set on 2019 dev audio.

            Overall: mean EER over all test sets.
