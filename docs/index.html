QUESTION 01

Can acoustic features improve SSL?

Does adding interpretable acoustic features to WavLM Base+ improve deepfake detection, particularly on unseen and degraded audio?

Start with LFCC. MFCC, CQCC, spectral descriptors and chroma are candidate follow-up features, not all mandatory experiments.*

Architectures

A1 · Classical baseline
LFCC → GMM

Official ASVspoof 2019 B02 reference. Provides an interpretable acoustic-feature baseline for analysing detection performance and failure modes. §

A2 · SSL baseline
WavLM Base+ → Neural Head

Frozen pretrained SSL encoder with a task-trained classifier. Establishes the performance of learned speech representations without explicit LFCC fusion. §

A4 · LFCC neural baseline
LFCC → Neural Head

Tests LFCC with neural classification instead of GMM. Provides an acoustic-only control for D1/D2 and enables feature-level attribution analysis. **

D1 · Simple fusion
LFCC WavLM → Concat + Head

Tests whether LFCC provides complementary information beyond WavLM representations.

D2 · Cross-attention fusion
LFCC WavLM → Cross-attn + Head

Tests whether learned interactions between LFCC and SSL representations outperform simple fusion. **

D3 · Bidirectional cross-attention
LFCC ↔ WavLM→Bi-cross-attn + Head

Tests whether reciprocal feature interaction improves over one-way attention (D2). **

Data & evaluation protocol

Stage 1 trains all models on ASVspoof 2019 LA to establish controlled baselines and evaluate cross-domain generalisation. If performance is insufficient, Stage 2 introduces SpoofCeleb training data to investigate whether greater speech and synthesis diversity improves robustness. Both stages use identical training data across architectures and evaluate on strictly held-out test sets.

Protocol lock

Split roles: Train learns detector parameters (raw audio); dev supports early stopping (raw during training) and threshold calibration (silence-trimmed for 2019 LA evaluation). Final metrics are reported on eval, controlled test subsets and external datasets. ASVspoof 2019 LA dev/eval and controlled eval conditions are trimmed during evaluation; external datasets remain raw. JEV/LAYA policy comparisons use dev only for calibration and send requests for held-out test clips, never dev calibration clips.

Train consistently, evaluate independently

Stage 1 trains on official 2019 LA train and validates on dev; dev is not a final benchmark. If Stage 2 is activated, use the same added SpoofCeleb training partition for each comparable architecture; never tune on external test sets.

Same clips, same metrics

Compare every system on identical manifests, preprocessing conditions and evaluation subsets.

Freeze before external tests

Use dev for model selection and threshold calibration; freeze choices before held-out eval, In-the-Wild and 2021 testing.

Reproducibility

Record split, seed, model checkpoint, decision prompt/version, feature schema, metric definitions and cost.

Two Views, One Truth (2025) Combines spectral features (MFCC, LFCC, CQCC) with SSL representations. Compares concatenation, cross-attention and gating mechanisms. Motivates testing whether handcrafted acoustic features complement WavLM representations. Use LFCC as the initial feature, with CQCC as a focused alternative. Compare simple concatenation (D1) against cross-attention (D2) to measure whether feature interaction adds value. D3 additionally tests bidirectional cross-attention against D2. Four public deepfake benchmarks
Exploring WavLM Back-ends (2024) Investigates WavLM representations with different classification back-ends, augmentation and calibration for spoof detection. Supports A2 as an SSL baseline. Use a pretrained WavLM encoder with a trainable classification head. Evaluate whether additional acoustic features improve on this reference rather than assuming SSL alone is sufficient. ASVspoof 5 Track 1
On Deepfake Voice Detection — It's All in the Presentation (2025) Investigates how audio presentation, communication channels and evaluation conditions affect deepfake detection. Motivates cross-domain and degradation evaluation. Test beyond ASVspoof 2019 LA using In-the-Wild, ASVspoof 2021 and controlled codec/noise conditions to assess real-world generalisation. Multi-corpus evaluation
Half-Truth Audio Detection and Localisation (2026) Uses cross-attentive fusion of handcrafted acoustic features for partially manipulated speech detection and localisation. Provides a related example of cross-attention for acoustic feature interaction. Supports investigating D2, while keeping partial-splice localisation outside EchoJEV's current research scope. MLADDC, HAD, PartialSpoof
Linear versus Mel Frequency Cepstral Coefficients (2011) Compares LFCC and MFCC frequency representations for speaker recognition. Establishes that LFCC and MFCC use different frequency resolutions, without establishing universal superiority. Start with LFCC for consistency with the official ASVspoof baseline; consider alternative acoustic features through ablation. NIST SRE 2010; speaker recognition
Mixture of Experts Fusion Using Frozen wav2vec 2.0 (2025) Uses a mixture-of-experts mechanism to combine representations from a frozen SSL encoder. Supports the feasibility of lightweight fusion with frozen SSL representations. Freeze WavLM in A2, D1 and D2 to reduce training cost and isolate the contribution of the fusion architecture. ASVspoof 2019 and 2021
Source Tracing: Detecting Voice Spoofing (2022) Studies synthesis-pipeline characteristics and their relationship to spoofed speech. Motivates examining attack-specific evidence and failure modes. Report per-attack performance alongside pooled EER to investigate whether detectors depend on generator-specific artifacts. ASVspoof 2019 LA
TADA (2025) Uses pretrained representations for training-free generator attribution and out-of-distribution detection. Motivates unseen-generator and out-of-domain diagnostics. Examine confidence, score distributions and errors when models encounter unfamiliar synthesis methods or recording conditions. ASVspoof 2019/2021/5, MLAAD, TIMIT
wav2vec 2.0 and Data Augmentation (2022) Investigates SSL-based spoof detection and data augmentation for improved robustness. Supports SSL-based anti-spoofing and robustness evaluation. Evaluate controlled noise and codec changes first; consider training augmentation only if the initial experiments justify it. ASVspoof 2021 LA and DF
Novelty boundary: Spectral + SSL concatenation and cross-attention have already been studied. Focus the contribution on your controlled comparison, failure-mode analysis, resource budget, and the added decision layer. Do not directly compare EER values across incompatible protocols.

Research notes & justifications

Explanations are deliberately collected here rather than interrupting the evaluation plan.

§

Why A1 and A2 are valid baselines

A1 — classical reference. LFCC-GMM (B02) is an official ASVspoof 2019 reference system, providing a reproducible non-neural comparator. ASVspoof 2019 protocol.

A2 — SSL representation reference. microsoft/wavlm-base-plus supplies pretrained general-purpose speech representations to a task-trained classifier. Stourbe et al. (2024) demonstrate the relevance of WavLM front-ends and back-end design to deepfake detection, although their fine-tuned ASVspoof 5 system is not identical to our frozen Base+ configuration. Model · Stourbe et al. · Chen et al..

Comparison principle. Use fixed 2019 LA train/dev splits and identical test conditions; report A1 whole-utterance versus A2 crop differences. Baselines are reproducible reference points, not claims of 2026 state-of-the-art.

*

Choosing acoustic features

LFCC first: it is already established by A1 and keeps the experiment focused. Zhou et al. compared LFCC with MFCC in speaker recognition and found benefits from linear-frequency resolution, including higher-frequency detail; that is a motivation, not proof that LFCC always detects deepfakes better. Zhou et al. (2011). El Kheir et al. (2025) directly examine MFCC, LFCC and CQCC alongside SSL features, making them the closest guide for follow-up comparisons. Two Views, One Truth. Keep chroma optional unless a concrete hypothesis justifies it.

**

Fusion experiment and ablation

Closest prior work: El Kheir et al. (2025) already compare SSL + spectral feature concatenation, cross-attention, mutual cross-attention and gating on public deepfake benchmarks. EchoJEV must therefore frame D1/D2/D3 as a controlled replication/adaptation and robustness study , not a novel fusion concept. El Kheir et al. . Wang et al. (2025) show that frozen wav2vec 2.0 layers can be fused through mixture-of-experts, supporting a resource-conscious frozen-encoder design. Wang et al. . Keep encoder, splits and training budget matched; compare A2 → D1 → D2 → D3, with seeds, parameter counts, LFCC-only control and attention-removal ablation. Cross-attention is not automatically an explanation. Half-truth localisation is related but a distinct task. Sutharya & Sasi (2026) .

***

How to evaluate JEV / LAYA

None of the nine reviewed papers establishes JEV/LAYA transparency, access or superiority. Verify documentation and outputs before claiming either is explainable. Use the same frozen base detector and a label-free evidence packet; prohibit true labels, filenames and dataset identifiers. Fix the policy on train/dev, then compare paired test decisions, error corrections versus introduced errors, calibration, latency and evidence faithfulness. Zhu et al. (2022) motivates generator-attribute evidence; TADA (2025) motivates source/OOD diagnostics. Neither paper validates JEV/LAYA. A transparent logistic-regression or rule-based policy remains a useful reproducible control.

†

Dataset decisions and limitations

MUSAN is a noise source, not a labeled real-vs-fake dataset. A “self clean” collection containing only authentic recordings cannot support EER/minDCF by itself; a controlled test requires both classes and consent/provenance. Use 2021 LA/DF only if audio, labels and usage terms are verified locally. SpoofCeleb and PhonemeDF are excluded from the core study because they add acquisition and compute burden without being essential to the two questions. External test sets remain untouched by training, hyperparameter selection and threshold fitting. Channel mismatch is a documented concern in Delgado et al. (2025/26); preserve original and degraded evaluation as paired tests.

‡

Metric interpretation

Specify minDCF target prior and error costs. EER and ROC AUC are threshold-independent ranking summaries; F1 depends on a preselected threshold. If a JEV/LAYA layer outputs only hard labels, report classification metrics and decision changes rather than manufacturing continuous-score EER/minDCF. For noisy conditions, use the same underlying source clips and report paired performance changes, not just absolute numbers.
